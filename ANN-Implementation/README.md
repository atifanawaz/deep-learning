# ANN Implementation Projects

This repository contains multiple **Artificial Neural Network (ANN) projects** implemented for both **regression** and **classification** tasks. Each project demonstrates how ANNs can be applied to real-world problems such as energy prediction, flight delays, churn modeling, employee attrition, loan default, stock trends, and used car price prediction.

## Projects Overview

This folder contains **8 ANN projects**, categorized as follows:

- **Regression Projects:** Predicting continuous numeric outcomes.
  - Building Energy Efficiency
  - Flight Delay Prediction
  - Household Energy Consumption
  - Used Car Price Prediction

- **Classification Projects:** Predicting categorical outcomes.
  - Churn Modeling
  - Employee Attrition Prediction
  - Loan Default Prediction
  - Stock Market Trend Prediction

Each project contains:
- A **Jupyter Notebook** with the full implementation of the ANN.
- A **README.md** detailing the project, dataset, preprocessing, model architecture, training, evaluation, and visualizations.

## Usage

1. Clone the repository:

```bash
git clone <repository-url>
cd deep-learning/ANN-Implementation
```

2. Navigate to the project folder you want to work on:
```
cd Used-Car-Price-Prediction-Regression-ANN
```

3. Open the corresponding Jupyter Notebook and run all cells.

Dependencies

```
Python 3.x

Jupyter Notebook

Libraries:

numpy

pandas

matplotlib

seaborn

scikit-learn

tensorflow or keras
```

You can install the dependencies using:

```
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow
```
